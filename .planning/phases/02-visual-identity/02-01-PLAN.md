**partials/navigation.hbs — Create the sidebar navigation partial:**

```handlebars
{{#if @site.navigation}}
<nav class="site-nav" aria-label="Primary navigation">
  {{#foreach navigation}}
  <a class="nav-link {{#if current}}is-active{{/if}}" href="{{url}}">{{label}}</a>
  {{/foreach}}
</nav>
{{/if}}
```

This overrides Ghost's default `{{navigation}}` output. The `current` helper provides active-link detection automatically.

**default.hbs — Add sidebar HTML structure:**

Replace the existing `<body>` content with:
```handlebars

                        <!-- X/Twitter SVG (16x16) -->

                        <!-- LinkedIn SVG (16x16) -->
                    </a>
```
