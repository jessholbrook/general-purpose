# General Purpose — Jess Holbrook's Personal Site

## What This Is

A personal website for Jess Holbrook built on Ghost.io, replacing the existing placeholder site at general-purpose.ghost.io. A clean, warm, content-forward home for writing, research, products, and experiments — exploring people, AI, and people + AI.

## Core Value

A sophisticated, simple personal site that makes Jess's work easy to find and pleasant to read.

### Active

- [ ] Custom Ghost theme with warm, serif-forward aesthetic
- [ ] Bold hero homepage with intro statement ("Jess writes about people, AI, and people + AI")
- [ ] Sidebar navigation (Blog, Publications, Products, Experiments, About)
- [ ] Blog section — posts listed reverse chronologically
- [ ] Publications section — academic publications from Google Scholar (manually curated initially)
- [ ] Products section — simple cards (image, name, description, link) for products built or contributed to
- [ ] Experiments section — cards linking out to external web experiments
- [ ] Dedicated About page with bio, photo, background
- [ ] Warm color palette: cream/off-white background, serif typography, terracotta/warm accent color
- [ ] Generous whitespace, minimal visual clutter, content-first layout

### Out of Scope

- Live Google Scholar integration — manual curation for v1, may automate later
- Newsletter/subscription functionality — not needed for launch
- Comments system — not a priority
- Search functionality — keep it simple
- Mobile app or PWA — web only

## Context

- Ghost.io hosted at general-purpose.ghost.io (existing site to be replaced from scratch)
- Custom Handlebars theme built from scratch for full design control
- Design inspiration: Manuel Moreale (ultra-minimal, warm accents), Mustafa Suleyman (sidebar nav, serif headings, thumbnail+text posts), People and Blogs (warm off-white, serif body, orange accent), Maggie Appleton (bold serif hero, personality-forward)
- Common design DNA across references: serif typography, warm tones (cream backgrounds, terracotta accents), generous whitespace, content-forward, no clutter
- Jess works at the intersection of people and AI — the site should feel thoughtful and human, not techy

## Constraints

- **Platform**: Ghost.io hosted — theme must be a valid Ghost Handlebars theme
- **Scope**: Personal site, not a complex web app — keep it simple and shippable
- **Content**: Publications maintained manually (not automated from Scholar API)
